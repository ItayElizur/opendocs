## Live debugging session (2026-08-24) — chart bug resisted 2 rounds of blind fixes

After PP-23's round 2 fixes, the user re-tested and the chart bug (RPC failure + wrong-scope-until-Edit-Data) recurred identically, plus SmartArt still couldn't change layout and table/chart/SmartArt selection still showed no pointer.
