## What is different about Excel

1. **`headerLines` is 11**, not 12 (Excel's file has no class-level comment block above the class declaration).
2. **Excel's file uses CRLF line endings.** The script preserves them automatically (it reads with `newline=''`). Do not "fix" line endings; a whole-file ending change would swamp the diff.
3. **Layout and charts are interleaved in the current file** — `InsertDeleteRows`/`InsertDeleteCols` sit *between* the formatting block and the chart block, while `SortRange` and the sheet operations sit *after* the charts. The script handles this (it assigns by name, not by position), but it is why the resulting diff will look larger than PowerPoint's.
4. **Excel is the biggest member count** (82) and gets the biggest single output file (`.Formatting.cs`, 14 members).

## Step 1 — Write the split config

Create `.split-work/excel.json` with **exactly** this content:

```json
{
  "source": "ExcelAiAddIn/ExcelTools.cs",
  "encoding": "utf-8",
  "headerLines": 11,
  "tailLines": 2,
  "groups": {
    "Read":          ["GetWorkbookContext","ReadRange","ReadCells","SelectRange","ReadFormats","HAlignName","VAlignName"],
    "Search":        ["ResolveSheetsToSearch","NativeFindInSheet","FindCells","FindReplaceExcel","NativeFindReplaceInSheet"],
    "SheetFeatures": ["ReadSheetFeatures","FindDataTables","TracePrecedents","TraceDependents"],
    "Operations":    ["RequiredFields","ProposeOperations","SetRangeValues"],
    "Formatting":    ["SetFilter","ClearFilter","SetFilterCriteria","MapCfOperator","GetCfNumber","MapCfTextMatch","AddConditionalFormat","HAlignMap","VAlignMap","BorderEdgeMap","OutlineEdges","AllEdges","FormatRange","ApplyBorders"],
    "Layout":        ["InsertDeleteRows","InsertDeleteCols","SortRange","SetRowHeight","SetColWidth","SetRowsHidden","SetColsHidden","SetFreeze","SetPageSetup","AddSheet","DeleteSheet","DuplicateSheet","SetSheetHidden","MoveSheet","ProtectSheet"],
    "Charts":        ["ApplyChartCategoryRange","AddChart","EditChartExcel","AddSparkline","AddShapeExcel","ResolveShapeByName","EditShapeExcel","DeleteVisual","AddImageExcel"],
    "Tables":        ["AddTable","ResolveTable","AddTableRow","AddTableColumn","DeleteTableRow","DeleteTableColumn","DeleteTable","MapPivotAgg","AddPivot","RefreshPivot"],
    "Data":          ["SetHyperlink","SetNote","CellAddressLike","ValidateDefinedNameSyntax","DefinedNameExists","AddDefinedName","DeleteDefinedName","SetDataValidation"]
  }
}
```

**Stays in `ExcelTools.cs`** (7 members, not listed above): `ModeByDoc`, `SetMode`, `ModeFor`, `ExcelErrorTexts`, `AlwaysAllowedTools`, `Execute`, `Sheet`.

**Grouping notes** — these are judgment calls already made; do not second-guess them mid-task:
- Filters and conditional formatting go in `.Formatting.cs` rather than their own file — together they are 14 members, and splitting them further would leave two files under 100 lines.
- Pivot tables (`MapPivotAgg`, `AddPivot`, `RefreshPivot`) go with `.Tables.cs`. A pivot is a table-shaped thing, and three members do not justify their own file.
- Shapes and images (`AddShapeExcel`, `EditShapeExcel`, `ResolveShapeByName`, `DeleteVisual`, `AddImageExcel`) go in `.Charts.cs` — Excel's `delete_visual` deletes both charts and shapes, so they share a vocabulary.

## Step 4 — Add the 9 files to the csproj

```bash
cd /c/dev/officeoffice
python - <<'PYEOF'
import io
p = "ExcelAiAddIn/ExcelAiAddIn.csproj"
t = io.open(p, encoding="utf-8-sig").read()
anchor = '    <Compile Include="ExcelTools.cs">\n      <SubType>Code</SubType>\n    </Compile>\n'
assert anchor in t, "anchor not found - open the csproj and add the entries by hand"
parts = ["Read","Search","SheetFeatures","Operations","Formatting","Layout","Charts","Tables","Data"]
add = "".join(
  '    <Compile Include="ExcelTools.%s.cs">\n'
  '      <SubType>Code</SubType>\n'
  '      <DependentUpon>ExcelTools.cs</DependentUpon>\n'
  '    </Compile>\n' % s for s in parts)
io.open(p, "w", encoding="utf-8-sig").write(t.replace(anchor, anchor + add, 1))
print("csproj: added", len(parts), "Compile entries")
PYEOF

grep -c "<Compile" ExcelAiAddIn/ExcelAiAddIn.csproj
```

**Expected:** `added 9`, then `15`.

If the `assert` fires, the anchor text does not match — open `ExcelAiAddIn/ExcelAiAddIn.csproj`, find the existing `<Compile Include="ExcelTools.cs">` block, and paste the nine entries after it by hand, following the same shape.
