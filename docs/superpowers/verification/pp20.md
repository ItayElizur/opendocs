## Deviations from plan

- **Task 1 Step 2 (strikethrough): implemented, then reverted — real PIA limitation, not a shortcut.** First attempt used `Shape.TextFrame2.TextRange.Font.Strikethrough` (the pattern Excel's own `ChartFormat.TextFrame2`/`TextRange2` uses, which does expose `Strikethrough` in Excel's PIA). This **failed to compile**: `CS0234: The type or namespace name 'TextRange2' does not exist in the namespace 'Microsoft.Office.Interop.PowerPoint'`. Cross-checked the PowerPoint PIA's own XML documentation directly — no `TextFrame2` member appears anywhere in it, unlike Excel's PIA where `ChartFormat.TextFrame2` is documented. Confirmed this is a genuine PIA gap, not a naming mistake, and followed the plan's explicit fallback: removed the field from both the handler and the schema rather than shipping a schema field the handler can't back (exactly the PP-12-style defect this plan's Global Constraints warn against reintroducing). Recorded in `docs/ai-tool-surface.md` as a documented limitation.
- No other deviations. Task 2 Step 3's alias/canonical-naming and Step 6's fill/line description note are implemented as specified.

## Everything noticed but not fixed (belongs to other items, not touched)

- **Cross-app field-name inconsistency (Task 3), confirmed by direct grep, not fixed (per the plan's own recommendation):** Word's `updateTextStyle` uses `font`/`sizeHalfPoints`/`color`; Excel's `format_range` uses `fontName`/`fontSize`/`fontColor`; PowerPoint's `set_element_style` (as this plan leaves it) uses `fontName`/`fontSize`/`color` — three different combinations for the same three concepts across the repo. Per the plan's explicit instruction, no renaming was done (would break saved conversations/prompts across three apps for a cosmetic gain); recorded here and in `docs/ai-tool-surface.md`'s item 4 for whoever reviews it next.
- **Word's `sizeHalfPoints` is the one naming difference that produces a wrong result rather than a rejected call** (a model sending `24` meaning 24pt silently gets 12pt) — flagged by the plan as deserving its own separate item, not folded into this one. Not filed as a new numbered PP item here; left as a note for whoever picks it up next.
